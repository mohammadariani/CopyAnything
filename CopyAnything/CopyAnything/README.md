# CopyAnything

## روش ۱: Android Studio
1. Android Studio را باز کنید → File > Open → پوشهٔ CopyAnything.
2. صبر کنید Gradle Sync تمام شود.
3. گوشی را با USB وصل کنید (USB debugging روشن) و Run بزنید.
   یا Build > Build APK(s) و فایل app/build/outputs/apk/debug/app-debug.apk را نصب کنید.

## روش ۲: بدون Android Studio (GitHub Actions)
1. یک ریپوی جدید در GitHub بسازید و محتویات این پوشه را در آن push کنید.
2. به تب Actions بروید؛ بعد از پایان بیلد، artifact به نام CopyAnything-debug-apk را دانلود کنید.
3. APK را روی گوشی نصب کنید.

## استفاده
1. اپ را باز کنید → «فعال‌سازی سرویس دسترسی‌پذیری» → CopyAnything را روشن کنید.
   (اندروید ۱۳+: Settings > Apps > CopyAnything > ⋮ > Allow restricted settings)
2. «خواندن متن صفحهٔ بعدی» را بزنید و در ۵ ثانیه به پست لینکدین بروید.
3. متن در اپ نمایش داده می‌شود؛ بخشی را انتخاب کنید یا «کپی همه» را بزنید.
